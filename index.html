Problem 1.1¶

$(C_L + (N-1)C_{fly} + \frac{T_{sw}}{2R_L})V_{out}[n] = (C_L - C_{fly})V_{out}[n-1] + C_{fly}V_{in}/C_L$

$(C_L + (N-1)C_{fly} + T_{sw})\tilde{V}_{out}(z) = (C_L - C_{fly})z^{-1}\tilde{V}_{out}(z) + C_{fly}\tilde{V}_{in}(z)$

$\frac{\tilde{V}_{out}(z)}{\tilde{V}_{in}(z)} = \frac{C_{fly}}{C_L + (N-1)C_{fly} + \frac{T_{sw}}{2R_L} - (C_L - C_{fly})z^{-1}}$

$\lim_{z \to 1} \frac{\tilde{V}_{out}(z)}{\tilde{V}_{in}(z)} = \frac{C_{fly}}{C_L + (N-1)C_{fly} - C_L + C_{fly} + \frac{T_{sw}}{2R_L}} = \frac{C_{fly}}{NC_{fly} + \frac{T_{sw}}{2R_L}}$

$= \frac{1}{N} \cdot \frac{1}{1 + \frac{T_{sw}}{2NC_{fly}R_L}} = \frac{1}{N} \cdot \frac{1}{1 + \frac{1}{2NR_L C_{fly} f_{sw}}} = \frac{1}{N} \frac{R_L}{R_L + \frac{1}{2NC_{fly} f_{sw}}}$

$= \frac{1}{2} \frac{R_L}{R_L + \frac{1}{4C_{fly} f_{sw}}}$

For $N=2$: $\frac{\tilde{V}_{out}(z)}{\tilde{V}_{in}(z)} = \frac{1}{2} \frac{1}{1 + \frac{1}{4R_L C_{fly} f_{sw}}}$ and $R_o = \frac{1}{4 C_{fly} f_{sw}}$

Problem 2.4

Charge multiplier vector for switches: $a_r = [q_{s0} : q_{s1} : q_{s2} : q_{s3} : q_{s4} : q_{s5} : q_{s6}]$

$a_r = [\frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3} \quad \frac{1}{3}]$

Note that if S5 and S6 are in series, S6 carries twice the current as S5 for a multiplier of 2/3.

Assume identical switch resistance R.

$R_{FSL} = 2 \sum_i R_i (a_{r,i})^2 = 2R \sum_{i=0}^6 (\frac{1}{3})^2 = 2R \cdot 7 (\frac{1}{3})^2 = \frac{14}{9}R$

Makes sense since for one half of the cycle three switches are on in series and in the other half only one equivalent switch is on.

Problems 3.1 and 3.2¶

Seeman & Sanders 2008 example

  • Phase 1:

$q_{out}^{(1)} = 0$

$q_3^{(1)} = q_x \Rightarrow q_2^{(1)} = -q_x$

$q_{IN}^{(1)} + q_1^{(1)} = q_2^{(1)} = -q_x \Rightarrow q_{IN}^{(1)} = q_2^{(1)} - q_1^{(1)} = -q_x - 2q_x = -3q_x$

  • Phase 2:

$q_{out}^{(2)} = q_o$

$q_3^{(2)} = -q_o = -q_x$

$q_2^{(2)} = q_x$

$q_{IN}^{(2)} = q_1^{(2)} = q_3^{(2)} - q_2^{(2)} = -q_x - q_x = -2q_x \Rightarrow q_1^{(1)} = +2q_x$

Vectors and Constraints

$q_{out} = q_{out}^{(1)} + q_{out}^{(2)} = 0 + q_o = q_o$

$q_x = q_o$

$q_{IN}^{(1)} = -3q_o \quad q_{IN}^{(2)} = -2q_o $

$q_1^{(1)} = 2q_o \quad q_1^{(2)} = -2q_o $

$ q_2^{(2)} = q_o$

$q_3^{(2)} = -q_o$

$q_{out}^{(2)} = q_o$

Switch resistance vector: $\vec{a}_r = [2 \quad 3 \quad 1 \quad 1 \quad 2 \quad 1 \quad 1 \quad 1 \quad 1 \quad 1]$

Capacitor voltage vector: $\vec{v}_c = [1 \quad 2 \quad 3] \Rightarrow \sum_i a_{ci} v_{ci} = 2+2+3=7$

Switch blocking voltage vector: $\vec{v}_r = [1 \quad 1 \quad 1 \quad 2 \quad 2 \quad 3 \quad 2 \quad 1 \quad 1 \quad 3] \Rightarrow \sum_k a_{rk} v_{rk} = 24$

Total Capacitor energy constraint:

$C_i = \vert{}\frac{a_{ci}}{v_{ci}}\vert{} \frac{2E_{tot}}{\sum_k \vert{}a_{ck} v_{ck}\vert{}}$

$C_1 = \vert{}\frac{2}{1}\vert{} \frac{2E_{tot}}{7} = (\frac{2}{7})2E_{tot}$

$C_2 = (\frac{2}{7})2E_{tot}$

$C_3 = (\frac{3}{7})2E_{tot}$

Total capacitance constraint:

$C_i^* = \frac{\vert{}a_{ci}\vert{}}{\sum_k \vert{}a_{ck}\vert{}} C_{tot}$

$\Rightarrow C_1 = (\frac{2}{4})C_{tot} \quad C_2 = (\frac{1}{4})C_{tot} \quad C_3 = (\frac{1}{4})C_{tot}$

Optimal Slow-Switching Limit Impedances:

  • Energy constrained: $R_{SSL}^* = \frac{1}{2E_{tot} f_{sw}} (\sum_i \vert{}a_{ci} v_{ci}\vert{})^2 = \frac{49}{2E_{tot} f_{sw}}$
  • Capacitance constrained: $R_{SSL}^* = \frac{1}{C_{tot} f_{sw}} (\sum_i \vert{}a_{ci}\vert{})^2 = \frac{16}{C_{tot} f_{sw}}$

Optimal Fast-Switching Limit Impedances:

Area constrained: $G_i^* = \frac{1}{R_i^*} = \vert{}\frac{a_{ri}}{V_{ri}}\vert{} \frac{A_{tot}}{\sum_k \vert{}a_{rk} V_{rk}\vert{}}$

$G_1 = (\frac{2}{1})\frac{A_{tot}}{24} \quad G_4 = (\frac{1}{1})\frac{A_{tot}}{24} \quad G_7 = (\frac{1}{2})\frac{A_{tot}}{24} \quad G_{10} = (\frac{1}{2})\frac{A_{tot}}{24}$

Problem 3.5¶

The voltage rating vector $\mathbf{v_{c}}$ for the capacitors (normalized to the input voltage) is found by inspection from the phase 1 and phase 2 circuits.

In phase 1:

  • $C_{1}$ is charged to $V_{IN} = v_{c,1}$
  • $C_{3}$ is charged to $V_{IN} + V_{c,2} = v_{c,3}$

In phase 2:

  • $C_{2}$ is charged to $V_{IN} + V_{c,1} = v_{c,2} = 2V_{IN}$

Therefore, $v_{c,3} = 3V_{IN}$ and $\mathbf{v_{c}} = [ 1, 2, 3] $. The sum of the products of the charge transfer vector elements and capacitor rating voltage vector elements $\Sigma |a_{c,i}v_{c,i}| = 7$, as confirmed in Table I from the Seeman 2008 paper.

The switch blocking voltage rating vector $\mathbf{v_{r}}$ (normalized to the input voltage) is also found by inspection from the phase 1 and phase 2 circuits.

In phase 1, switches 2, 4, 6, 8, and 10 are open circuits:

  • $SW_{2}$ blocks $V_{IN}$ (it is in parallel with $C_{1}$)
  • $SW_{4}$ blocks $V_{IN}$ (it is also in parallel with $C_{1}$)
  • $SW_{6}$ blocks $v_{c,2} = 2V_{IN}$ (it is in parallel with $C_{2}$)
  • $SW_{8}$ blocks $v_{c,3} = 3V_{IN}$ (it is in parallel with $C_{3}$)
  • $SW_{10}$ blocks $V_{OUT} - v_{c,3} = 5V_{IN} - 3V_{IN} = 2V_{IN}$

In phase 2, switches 1, 3, 5, 7, and 9 are open circuits:

  • $SW_{1}$ blocks $V_{IN}$ (it is in parallel with $V_{IN}$)
  • $SW_{3}$ blocks $V_{IN}$ (it is in parallel with $C_{1}$)
  • $SW_{5}$ blocks $v_{c,2} = 2V_{IN}$ (it is in parallel with $C_{2}$)
  • $SW_{7}$ blocks $v_{c,2} = 2V_{IN}$ (it is also in parallel with $C_{2}$)
  • $SW_{9}$ blocks $v_{c,3} = 3V_{IN}$ (it is in parallel with $C_{3}$)

Therefore, $\mathbf{v_{r}} = [ 1, 1, 1, 1, 2, 2, 2, 3, 3, 2 ] $. The sum of the products of the charge transfer vector elements and capacitor rating voltage vector elements $\Sigma |a_{r,i}v_{r,i}| = 24$, as confirmed in Table I from the Seeman 2008 paper.
